This folder contains notebooks for visualizations and analyses in the paper. We recommend running them in a virtual environment with [dtaianomaly](https://github.com/ML-KULeuven/dtaianomaly) installed (unless specified otherwise), because some visualizations depend on it:

```bash
pip install dtaianomaly[notebook]
```

Some of the notebooks depend on intermediate experimental results, which can be downloaded from [here](https://rdr.kuleuven.be/dataset.xhtml?persistentId=doi:10.48804/MCVI4N). The downloaded intermediate results should be extracted to `/results/intermediate/`.

In a few notebooks, we used the experimental results of [the TSB-AD paper](https://github.com/thedatumorg/TSB-AD/tree/main) (`uni_mergedTable_VUS-PR.csv` as in [this directory](https://github.com/thedatumorg/TSB-AD/tree/main/benchmark_exp/benchmark_eval_results) of their repository) for comparison purposes or to get information on the anomaly length.

Below, we give a brief introduction to what each notebook is about, unless the file name is already self-evident. Next to the file name of each notebook, we mention figures and tables in the paper that are generated by it.
